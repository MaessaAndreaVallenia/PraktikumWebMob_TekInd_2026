## Cara Menjalankan Proyek
Untuk menjalankan aplikasi ini di komputer lokal, ikuti langkah-langkah berikut:

1. Buka terminal di dalam folder proyek ini.
2. Ketik perintah berikut untuk menginstal semua dependencies:
   ```bash
   npm install
3. Setelah proses instalasi selesai, jalankan server pengembangan dengan perintah:
    Bash
    npm run dev
    Buka tautan localhost yang muncul di terminal menggunakan browser.
